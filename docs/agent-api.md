# Agent Data API (dealer-scoped)

The Agent Data API lets a dealer's own AI agent (e.g. a Zenith Code WhatsApp
assistant) read **that dealer's** live listings and create leads on the dealer's
behalf. It is a **live HTTP pull** — NivaasBhoomi never pushes to the agent.

Every request is scoped to a single dealer by an API key. A key can only ever
see and act on its own dealer's data — there is no way to reach another dealer's
listings, and seed/demo listings and buyer PII are never exposed.

- **Base URL:** `https://www.nivaasbhoomi.com`
- **Auth header:** `X-Agent-Key: nb_agent_…`
- **Content type:** `application/json`

---

## Authentication

Each dealer has (at most) one Agent API key, generated by a NivaasBhoomi admin
from the dealer's admin page. The key looks like:

```
nb_agent_8Jd2f...   (prefix "nb_agent_" + 32 random bytes, base64url)
```

Pass it on every request:

```
X-Agent-Key: nb_agent_8Jd2f...
```

Notes:

- The plaintext key is shown **once**, at generation time. NivaasBhoomi stores
  only a SHA-256 hash + the last 4 characters — it cannot show the key again.
- **Regenerating** a key invalidates the old one **immediately**.
- The key is **never** written to logs or returned in any response.

### Auth & rate-limit errors

| Situation | HTTP | `error.code` |
| --- | --- | --- |
| No `X-Agent-Key` header | 401 | `UNAUTHORIZED` |
| Unknown / revoked key | 401 | `UNAUTHORIZED` |
| Dealer account not `active` (paused/banned) | 403 | `FORBIDDEN` |
| Over the rate limit | 429 | `RATE_LIMITED` (+ `Retry-After` header) |

### Rate limits

Per key:

- **60 requests / minute**
- **2000 requests / day**

When exceeded, the response is `429` with a `Retry-After` header (seconds):
`60` when the per-minute cap is hit, `3600` when the per-day cap is hit.

Every request is logged (dealer, endpoint, HTTP status, latency) for 30 days.
The key itself is never logged.

---

## Response envelope

Every response uses the same envelope.

Success:

```json
{ "success": true, "data": { /* ... */ } }
```

Error:

```json
{ "success": false, "error": { "code": "VALIDATION_ERROR", "message": "…" } }
```

### Error codes

| `code` | HTTP | Meaning |
| --- | --- | --- |
| `UNAUTHORIZED` | 401 | Missing or invalid API key |
| `FORBIDDEN` | 403 | Dealer account is not active |
| `NOT_FOUND` | 404 | Route not found |
| `VALIDATION_ERROR` | 422 | Bad params/body, invalid phone, or a lead on a seed listing |
| `RATE_LIMITED` | 429 | Rate limit exceeded (`Retry-After` header) |
| `SERVER_ERROR` | 500 | Unexpected server error |

## `GET /api/agent/search`

Returns the authenticated dealer's **approved, non-seed** listings. Scope is the
dealer behind the key — never a request parameter.

### Query parameters

| Param | Type | Notes |
| --- | --- | --- |
| `city` | string | City **slug** (e.g. `pune`). Unknown slug → empty result. |
| `locality` | string | Locality **slug** within `city`. Requires `city`. |
| `type` | string | Property type (e.g. `flat`, `plot`, `house`, `commercial`). |
| `purpose` | string | `sale` or `rent`. |
| `budget_min` | number | Min price. On `sale` uses expected price; on `rent` uses monthly rent. |
| `budget_max` | number | Max price (same field as above). |
| `bhk` | string | e.g. `2`, `3`. |
| `listingId` | string | Return a single listing's **full** detail. Must belong to the key's dealer and be approved + non-seed; otherwise the result is empty. |
| `limit` | number | Default `10`, max `25`. |
| `cursor` | string | Opaque cursor from a previous `nextCursor`. |

Results are newest-first and cursor-paginated.

### Response `data`

```json
{
  "items": [
    {
      "id": "665f1c2a9b4e2a0012a3b4c5",
      "title": "2 BHK flat in Baner",
      "publicUrl": "https://www.nivaasbhoomi.com/property/2-bhk-flat-in-baner-xxxx",
      "price": 8500000,
      "city": "Pune",
      "locality": "Baner",
      "type": "flat",
      "purpose": "sale",
      "bhk": "2",
      "area": 950,
      "areaUnit": "sq.ft.",
      "description": "Spacious 2 BHK with covered parking…",
      "imageUrl": "https://res.cloudinary.com/…/cover.jpg",
      "status": "approved",
      "updatedAt": "2026-09-01T10:20:30.000Z"
    }
  ],
  "nextCursor": "665f1c2a9b4e2a0012a3b4c5"
}
```

- `nextCursor` is `null` on the last page.
- In list mode `description` is truncated to ~240 chars; a `listingId` detail
  request returns the full description.
- **No buyer PII is ever returned.** `publicUrl` is always an absolute
  `https://www.nivaasbhoomi.com` link.

### Examples

```bash
# All of this dealer's listings (first page)
curl -H "X-Agent-Key: $KEY" \
  "https://www.nivaasbhoomi.com/api/agent/search"

# Filtered: 2 BHK flats for sale in Baner, Pune, up to ₹90L
curl -H "X-Agent-Key: $KEY" \
  "https://www.nivaasbhoomi.com/api/agent/search?city=pune&locality=baner&type=flat&purpose=sale&bhk=2&budget_max=9000000"

# One listing's full detail
curl -H "X-Agent-Key: $KEY" \
  "https://www.nivaasbhoomi.com/api/agent/search?listingId=665f1c2a9b4e2a0012a3b4c5"

# Next page
curl -H "X-Agent-Key: $KEY" \
  "https://www.nivaasbhoomi.com/api/agent/search?limit=10&cursor=665f1c2a9b4e2a0012a3b4c5"
```

## `POST /api/agent/lead`

Creates a lead for the key's dealer, from the dealer's own WhatsApp agent
(`source = "whatsapp_agent"`). The lead is assigned **directly** to the dealer
(the normal rotation is bypassed) and pinned (no SLA auto-reassignment) — it is
the dealer's own traffic.

### Request body

```json
{
  "name": "Asha Verma",
  "phone": "9876543210",
  "listingId": "665f1c2a9b4e2a0012a3b4c5",
  "message": "Wants a site visit this weekend",
  "intent": "buy"
}
```

| Field | Required | Notes |
| --- | --- | --- |
| `phone` | ✅ | 10-digit Indian mobile (with or without `+91`/`91`). Normalized to `91XXXXXXXXXX`. |
| `name` | — | Buyer's name. |
| `listingId` | — | The listing the buyer asked about. Attached only if it is this dealer's approved, non-seed listing; a cross-dealer id is ignored (lead is still created, just not tied to a listing). |
| `message` | — | Free text. |
| `intent` | — | Short intent tag, e.g. `buy`, `rent`, `site-visit`. |

### Response `data`

```json
{
  "leadId": "665f2d3b0c5f3b0013b4c5d6",
  "deduped": false,
  "assigned": true
}
```

- `deduped: true` means an identical enquiry (same phone + listing, or same
  phone + dealer) already arrived in the last **24 hours**; no new lead is
  created and `leadId` points at the existing lead.
- `assigned: true` means the lead was assigned to the dealer on this call.

### Errors

| Situation | HTTP | `error.code` |
| --- | --- | --- |
| Missing/invalid `phone` | 422 | `VALIDATION_ERROR` |
| `listingId` is a **seed/demo** listing | 422 | `VALIDATION_ERROR` |
| Malformed JSON body | 422 | `VALIDATION_ERROR` |

### Example

```bash
curl -X POST \
  -H "X-Agent-Key: $KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"Asha Verma","phone":"9876543210","listingId":"665f1c2a9b4e2a0012a3b4c5","intent":"buy","message":"site visit this weekend"}' \
  "https://www.nivaasbhoomi.com/api/agent/lead"
```

---

## Security guarantees

- **No cross-dealer access.** The dealer scope always comes from the server side
  (the key), never from a request parameter. A key cannot read or write another
  dealer's data by any parameter.
- **Seed listings are never exposed** in search and cannot receive leads.
- **Buyer PII is never returned** by the search endpoint.
- **The key is never stored in plaintext**, never logged, and never returned in
  any response (except the one-time generation response in the admin UI).

## Zenith Code tool schemas

Function-calling JSON schemas for a Zenith agent. The agent stores the dealer's
`nb_agent_…` key as a secret and sends it as `X-Agent-Key` on every call.

### `search_properties`

```json
{
  "name": "search_properties",
  "description": "Search this dealer's live NivaasBhoomi property listings. Returns only this dealer's approved listings (never other dealers', never demo listings). Use it to answer buyer questions about what the dealer has, filter by city/locality/type/budget/BHK, or fetch one listing's full detail by id.",
  "parameters": {
    "type": "object",
    "properties": {
      "city": { "type": "string", "description": "City slug, e.g. \"pune\". Lowercase." },
      "locality": { "type": "string", "description": "Locality slug within the city, e.g. \"baner\". Requires city." },
      "type": { "type": "string", "description": "Property type: flat, plot, house, or commercial." },
      "purpose": { "type": "string", "enum": ["sale", "rent"], "description": "Whether the buyer wants to buy or rent." },
      "budget_min": { "type": "number", "description": "Minimum price in INR. For rent this is monthly rent." },
      "budget_max": { "type": "number", "description": "Maximum price in INR. For rent this is monthly rent." },
      "bhk": { "type": "string", "description": "Number of bedrooms, e.g. \"2\" or \"3\"." },
      "listingId": { "type": "string", "description": "If the buyer refers to a specific listing, its id — returns that one listing's full detail." },
      "limit": { "type": "number", "description": "Max results, 1–25. Default 10." },
      "cursor": { "type": "string", "description": "Pagination cursor from a previous response's nextCursor. Omit for the first page." }
    },
    "required": []
  }
}
```

### `create_lead`

```json
{
  "name": "create_lead",
  "description": "Record a buyer enquiry as a lead for this dealer on NivaasBhoomi. Call it once you have the buyer's phone number and know which listing (if any) they're interested in. The lead is assigned straight to this dealer. Duplicate enquiries from the same phone within 24 hours are merged automatically.",
  "parameters": {
    "type": "object",
    "properties": {
      "phone": { "type": "string", "description": "The buyer's 10-digit Indian mobile number." },
      "name": { "type": "string", "description": "The buyer's name, if known." },
      "listingId": { "type": "string", "description": "The id of the listing the buyer asked about, if any (from search_properties)." },
      "message": { "type": "string", "description": "A short note on what the buyer wants." },
      "intent": { "type": "string", "description": "Short intent tag, e.g. \"buy\", \"rent\", or \"site-visit\"." }

    "required": ["phone"]
  }

```
